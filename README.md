# SamOTA (Android)

Baixador de firmware Samsung via FUS (Smart Switch / Kies), direto do servidor oficial.

**Desenvolvedor:** Llucs

## Recursos
- Consulta de firmware (BIN / tamanho / MODEL_PATH)
- Download com múltiplas conexões + limite de velocidade
- Retomar download automaticamente
- Decriptação de `.enc2` / `.enc4` para `.zip`

## Aviso
Use apenas para uso pessoal e com seu próprio aparelho. Você é responsável pelo que fizer com os arquivos baixados.
